## Selected sources (chosen in Sprint 2)

These are the sources the art direction (`docs/gdd.md` section 8) points at. Each imported file has its own row in the table above. Andika and the Kenney files were imported on 2026-10-17; the gems, backdrops, title picture, museum minerals and the Dig and Museum icons stay drawn in code (the gems because the Kenney gem sprites share one shape and the game needs gems that differ by shape as well as color). The music loops stay project-synthesized because Kenney publishes no loops.
