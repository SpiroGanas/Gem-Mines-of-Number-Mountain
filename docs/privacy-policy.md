## The short version

Gem Mines of Number Mountain is a math game for children aged 6 to 12. It works completely offline.

- The app does not ask Android for internet access, so it cannot send anything anywhere.
- We do not collect any information about your child or your family. Nothing is sent to us or to anyone else.
- There are no ads, no in-app purchases, no accounts, no sign-in, no chat and no analytics.
- Everything the game remembers stays on your device. It only leaves the device if a parent, inside the parent area, chooses to save a progress file and then moves that file somewhere.
- Handwritten answers are read on the device and thrown away straight after. No picture of your child's writing is ever made or kept.

## What the game stores on your device

The game keeps the following on the device, in the app's private storage. Other apps cannot read it.

For each child profile (up to four on one device):

- a **nickname** that a parent types in the parent area. We suggest a first name or a made-up name, not a full name;
- a **picture** (avatar) chosen from the game's own pictures, and a **starting grade**;
- **learning progress**: which math skills the child has practised, the game's estimate of how well each one is known, and a history of answers (which kind of problem, when, whether the answer was right, how many hints were used, how long it took, and whether it was typed, tapped or handwritten);
- **rewards and things made in the game**: coins, gems, badges, Word Gems, crafted items, builds, and the days the lantern was lit;
- **settings**: session length, interface mode, handwriting coaching, and family reward points and goals that a parent set up.

For the device as a whole:

- sound and music volumes, and whether handwritten answers are switched on;
- a **random device label** made from random numbers when the game first runs. It is not taken from the device's hardware or from any Google or Android ID. It is only used to name progress files and to tell your devices apart when you move progress between them;
- a short log of progress files a parent saved or loaded, and up to five backup copies of progress that a loaded file replaced.

The game does **not** use Android's automatic cloud backup: it switches that off (`allowBackup="false"`), so the game's data is not copied to a Google backup.

## Handwriting

On a touch screen, a child can write an answer with a finger or a stylus. The game reads the writing on the device, with a small digit reader built into the game itself (no outside service or library). The pen strokes are held in memory only while the child can see them. They are discarded as soon as the answer is submitted or erased. The game never turns the writing into a picture, never saves it, and never sends it anywhere.

## What we never collect

The game does not collect, store or share:

- location (precise or approximate);
- contacts, photos, videos, files outside the game, or the calendar;
- the camera or the microphone (the game does not ask for either);
- the advertising ID or any other device identifier from Android or Google;
- account names, email addresses, phone numbers or payment details;
- usage analytics, crash reports or diagnostics sent off the device;
- images or recordings of handwriting.

## When information leaves the device

Only when a parent decides. The parent area is behind a grown-up question that a young child cannot easily answer. In the parent area, a parent can **export progress**: the game asks Android's own file picker where to save one progress file, and writes it there. The file holds the child's profile (including the nickname) and the history of answers, so the same progress can be loaded on another device. Where the file goes next (a USB stick, a shared folder, a cloud drive) is the parent's choice and is handled by the app the parent picks, not by this game. We never receive the file unless you send it to us yourself.

A parent can also **import** a progress file in the same way. The game reads only the file the parent picks.

## The web version

The game can also be played in a web browser. The page loads the game files from our host (GitHub Pages) once; after that the game makes no network requests of its own. The host keeps ordinary web access logs (such as the time and your network address), which the game never reads and we do not use. Progress is saved in the browser's own storage on your device (not on a server); clearing the site data in the browser erases it. Handwriting is read on your device, as in the app, and the drawing is thrown away at once; where there is no touch screen, a number pad is shown instead. Everything else in this policy applies to the web version too, except the progress file: the web version has no export or import (a web page cannot save a file to your computer or read one from it through the game's own dialog), so progress stays in that browser on that device. To move progress between devices, use the app.

## Third parties

The game contains no third-party software that collects data: no advertising, analytics, crash-reporting or social SDKs. It is built with the Godot game engine (open source), which collects nothing. It uses a font and art and sound files with open licences; these are files, not software. The full list is in the project's SDK audit.

Google Play handles the download and updates of the app under Google's own privacy policy.

## Children's privacy

The game is designed for children. Because it does not collect personal information from anyone, it does not collect personal information from children. The nickname and the progress stay on the device unless a parent exports them, as described above. This is how we meet the expectations of laws that protect children's privacy, such as COPPA in the United States and the GDPR and the UK Children's Code in Europe and the UK.

## Deleting your data

- **One child:** delete that child's profile in the parent area.
- **Everything:** uninstall the game. Android removes everything the game stored, including the backups and the device label.
- **Exported files** are wherever you saved them. The game does not track or delete them; delete them where you put them.

Because we hold no data about you, there is nothing for us to delete on our side.
